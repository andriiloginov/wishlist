# Вішліст на день народження (GitHub Pages + Google-таблиця)

## 1. Скрипт у таблиці
1. Відкрийте таблицю «Вішліст на день народження» у Google Drive.
2. Відкрийте меню **Розширення → Apps Script** (англ. **Extensions → Apps Script**).
3. Видаліть усе з файлу `Code.gs`, вставте вміст `Code.gs` з архіву і натисніть 💾.
4. Натисніть **Розгорнути → Нове розгортання** (англ. **Deploy → New deployment**).
   - Тип (⚙️): **Вебдодаток** (англ. **Web app**)
   - Виконувати як (англ. Execute as): **Я** (англ. **Me**)
   - Хто має доступ (англ. Who has access): **Усі** (англ. **Anyone**)
5. Натисніть **Розгорнути** і дозвольте доступ до своєї таблиці. Google покаже попередження «додаток не перевірено»: натисніть **Advanced → Go to … (unsafe)**. Це ваш власний скрипт.
6. Скопіюйте **URL вебдодатку**. Він закінчується на `/exec`.

## 2. Сторінка
1. Відкрийте `index.html` текстовим редактором і впишіть URL:
   ```js
   const API_URL = "https://script.google.com/macros/s/…/exec";
   ```
2. На GitHub створіть публічний репозиторій `wishlist`, натисніть **Add file → Upload files** і завантажте `index.html`.
3. Відкрийте **Settings → Pages**, виберіть Branch: `main`, папку `/ (root)` і натисніть **Save**.
4. Через хвилину-дві сайт буде на `https://ваш-нік.github.io/wishlist/`. Це посилання для гостей.

## Як вести список
- Подарунки задані в масиві `ITEMS` у `index.html`. Поле `id` після публікації не змінюйте, бо до нього прив'язані резерви.
- У таблиці зберігаються тільки резерви: **ID подарунка | Хто дарує | Токен**. Скрипт заповнює її сам.
- Щоб звільнити резерв, видаліть рядок цього подарунка з таблиці.
- Саму таблицю гостям не надсилайте, тільки посилання на сайт.

Якщо змінили код скрипту, перейдіть у **Розгорнути → Керування розгортаннями → ✏️ → Версія: Нова**. Тоді адреса залишиться та сама.
