# Вішліст на день народження (GitHub Pages)

Статична сторінка: один файл `index.html`, без бекенду.

## Як додати подарунок
Допишіть рядок у масив `ITEMS` на початку `index.html`:
```js
{ title: "Назва", note: "Платформа", price: "999 ₴", link: R + "slug-товару", img: I + "шлях/до/картинки.png" },
```
`R` — це адреса сторінки товару на retromagaz, `I` — адреса папки з картинками товарів.
